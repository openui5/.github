# :fire: OpenUI5 GitHub Organization (Archived)

> **Looking for active UI5 projects?** Head over to the **[UI5 GitHub organization](https://github.com/UI5)** — the central location for all UI5-related open-source projects maintained by SAP SE.

## About this organization

This GitHub organization was previously used to distribute [OpenUI5](https://openui5.org/) releases via [Bower](https://bower.io/). Individual OpenUI5 libraries were published here as separate repositories so that they could be consumed through the Bower package manager.

**This Bower-based setup was discontinued after OpenUI5 version 1.58.** All repositories in this organization have been archived and are no longer maintained.

## Where to go instead

For all active UI5 open-source projects — including OpenUI5, UI5 Web Components, UI5 CLI, and more — please visit:

* **[github.com/UI5](https://github.com/UI5)** — the central UI5 GitHub organization maintained by SAP SE
